# Product Preview Card Component

A responsive product preview card built for the Frontend Mentor challenge.

## Built With

- HTML5
- CSS3
- Flexbox
- CSS custom properties
- Media queries
- Google Fonts

## Features

- Responsive mobile and desktop layouts
- Product details and pricing
- Hover effect on the Add to Cart section
- Custom fonts and colors

## What I Learned

- Creating layouts using Flexbox
- Making designs responsive with media queries
- Using CSS variables
- Styling images with `object-fit` and `border-radius`
